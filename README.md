# 👀 ZizysBot
Um bot que toca músicas em call do WhatsApp + Comandos que na minha opinião é divertido;)

---
## 📦 Instalação + Execução
```bash
git clone https://github.com/maurikkkkj/ZizysBot
cd ZizysBot
npm install
npm start
```

---
👍 Esse bot é tão leve que vai rodar na sua maquina ou na sua bomba de celular via termux.

---
⚠️ Para uma "melhor" performance na ligação. É recomendado o uso de VPS ou uma host de sua preferência. Agora caso sua internet seja rápida igual a do elon musk não tem problema. 😎
